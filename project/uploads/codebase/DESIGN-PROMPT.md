# Prompt สำหรับ Claude Design

คัดลอกทั้งหมดด้านล่างไปวางใน Claude Design พร้อมแนบโฟลเดอร์ `codebase/app/` แล้วเติมสิ่งที่อยากให้ปรับในหัวข้อสุดท้าย

---

## บริบท

นี่คือ **ระบบเบิกพัสดุของโรงพยาบาลตาพระยา** (โรงพยาบาลชุมชนในประเทศไทย) เป็นเว็บแอปภายในโรงพยาบาล หน่วยงานต่าง ๆ ใช้เบิกวัสดุจากคลังกลาง เช่น วัสดุการแพทย์ วัสดุสำนักงาน วัสดุงานบ้าน

ไฟล์ที่แนบเป็นหน้าเว็บที่ใช้งานจริง (HTML + CSS + JavaScript ล้วน ไม่มี framework) มี `mock-api.js` จำลองข้อมูลให้เปิดดูได้ทันที

## ผู้ใช้

1. **เจ้าหน้าที่หน่วยงาน** (พยาบาล เจ้าหน้าที่ธุรการ) — ใช้ไม่บ่อย ไม่ถนัดคอมพิวเตอร์มาก ต้องการเบิกของให้เสร็จเร็ว บางคนใช้แท็บเล็ตหรือมือถือ
2. **เจ้าหน้าที่คลังพัสดุ (ผู้ดูแลคลัง)** — ใช้ทุกวัน บนคอมพิวเตอร์ ต้องเห็นใบเบิกที่ค้างและสินค้าใกล้หมดได้ทันที

## ขั้นตอนการทำงาน (ห้ามเปลี่ยน)

1. หน่วยงานเลือกสินค้า + จำนวน (แต่ละสินค้ามี **หน่วยนับเดียว** เช่น กล่อง ห่อ ขวด รีม) ใส่ชื่อ **ผู้เบิก** แล้วส่งใบเบิก → สถานะ "รออนุมัติ"
2. คลังอนุมัติ (แก้ลดจำนวนได้) ใส่ชื่อ **ผู้อนุมัติ** → "อนุมัติแล้ว รอจ่าย" หรือไม่อนุมัติพร้อมเหตุผล → "ไม่อนุมัติ"
3. คลังจ่ายของ ใส่ชื่อ **ผู้จ่าย** และ **ผู้รับ** → "จ่ายแล้ว" (สต็อกถูกตัดตอนนี้)
4. หน่วยงานยกเลิกได้เฉพาะตอน "รออนุมัติ"
5. พิมพ์ใบเบิก A4 พร้อมช่องเซ็นชื่อ 4 ช่อง: ผู้เบิก ผู้อนุมัติ ผู้จ่าย ผู้รับ

## หน้าจอที่มี

| หน้า | ใครเห็น | เนื้อหา |
|---|---|---|
| เข้าสู่ระบบ / ตั้งค่าครั้งแรก | ทุกคน | ชื่อผู้ใช้ รหัสผ่าน |
| เบิกสินค้า | ทุกคน | ตารางสินค้า (ค้นหา กรองหมวด ช่องจำนวน + หน่วย) และแผงใบเบิกด้านขวา |
| ใบเบิก | ทุกคน (หน่วยงานเห็นเฉพาะของตัวเอง) | รายการใบเบิก กรองตามสถานะ กดดูรายละเอียด/อนุมัติ/จ่าย/พิมพ์ในกล่องข้อความ |
| ภาพรวม | ผู้ดูแลคลัง | ตัวเลขสรุป ใบเบิกที่ต้องดำเนินการ สินค้าใกล้หมด สินค้าจ่ายออกมากสุด 30 วัน |
| สินค้า/สต็อก | ผู้ดูแลคลัง | เพิ่ม/แก้ไขสินค้า รับเข้า/ปรับสต็อก ดูประวัติรายสินค้า งดเบิก |
| ประวัติสต็อก | ผู้ดูแลคลัง | ทุกการรับเข้า/จ่ายออก พร้อมยอดคงเหลือ |
| หน่วยงาน, ผู้ใช้ | ผู้ดูแลคลัง | จัดการหน่วยงานและบัญชี |

สถานะใบเบิกและสี: รออนุมัติ (เหลือง), อนุมัติแล้ว รอจ่าย (น้ำเงิน), จ่ายแล้ว (เขียว), ไม่อนุมัติ (แดง), ยกเลิก (เทา)

## ข้อกำหนดการออกแบบ

- ภาษาไทยทั้งหมด ฟอนต์ต้องอ่านภาษาไทยได้ชัด (ปัจจุบันใช้ Segoe UI / Leelawadee UI / Noto Sans Thai)
- วันที่แสดงเป็น พ.ศ. รูปแบบ `26/09/2569 21:19`
- ต้องรองรับทั้งโหมดสว่างและมืด ใช้สีผ่านตัวแปร CSS ใน `:root` (ดู `style.css`) สีหลักปัจจุบันคือเขียวอมฟ้าแบบโรงพยาบาล `#0f766e`
- ใช้บนมือถือได้ (กว้าง 375px) โดยไม่มีการเลื่อนแนวนอนทั้งหน้า
- ตารางตัวเลขชิดขวา ปุ่มสำคัญต้องเห็นชัด ปุ่มที่ทำลายข้อมูลใช้สีแดง
- หน้าพิมพ์ต้องเป็นขาวดำ อ่านง่าย พอดี A4

## ข้อจำกัดทางเทคนิค (เพื่อให้นำดีไซน์กลับไปใช้ได้)

- ใช้ HTML/CSS/JavaScript ธรรมดา ไม่ใช้ React หรือ framework อื่น ไม่โหลดไลบรารีจากอินเทอร์เน็ต (เครือข่ายโรงพยาบาลอาจปิดอินเทอร์เน็ต)
- คง `id` และ `class` ที่ `app.js` ใช้อ้างอิงไว้ เช่น `#view`, `#tabs`, `#userbox`, `#dlg`, `#toast`, `#print`, `.qty-input`, `.pick-qty`, `.cart-qty`, `data-act`, `data-tab`
- ชื่อฟิลด์ข้อมูลต้องตรงกับ API เดิม (เช่น `requester_name`, `approver_name`, `issuer_name`, `receiver_name`, `qty_requested`, `qty_approved`, `qty_issued`)
