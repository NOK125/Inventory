# codebase — ชุดสำหรับ Claude Design

โฟลเดอร์นี้คือหน้าเว็บของระบบเบิกพัสดุ รพ.ตาพระยา ในแบบที่ **เปิดได้เองโดยไม่ต้องรันเซิร์ฟเวอร์** ใช้สำหรับนำไปออกแบบหน้าตาต่อใน Claude Design หรือเปิดดูตัวอย่าง

| ไฟล์ | คืออะไร |
|---|---|
| `DESIGN-PROMPT.md` | ข้อความสำหรับวางใน Claude Design อธิบายระบบ ผู้ใช้ หน้าจอ และสิ่งที่ห้ามเปลี่ยน |
| `app/index.html` | หน้าเว็บ ดับเบิลคลิกเปิดได้เลย |
| `app/app.js`, `app/style.css` | โค้ดหน้าเว็บและสไตล์ (สำเนาจาก `static/`) |
| `app/mock-api.js` | จำลองเซิร์ฟเวอร์พร้อมข้อมูลตัวอย่าง (หน่วยงาน สินค้า ใบเบิกทุกสถานะ) |

## วิธีใช้กับ Claude Design

1. เปิด Claude Design แล้วแนบโฟลเดอร์ `codebase/` นี้ (หรือไฟล์ในโฟลเดอร์ `app/`)
2. คัดลอกข้อความใน `DESIGN-PROMPT.md` ไปวาง แล้วบอกสิ่งที่อยากปรับ เช่น "ปรับหน้าเบิกสินค้าให้ใช้บนแท็บเล็ตง่ายขึ้น"
3. ได้ดีไซน์ที่พอใจแล้ว นำ HTML/CSS ที่ได้กลับมาให้ AI ปรับเข้า `static/` ของโปรเจกต์ (ดู `CLAUDE.md` ที่รากโปรเจกต์)

## โหมดตัวอย่าง

- เปิดมาจะล็อกอินเป็น **ผู้ดูแลคลัง** ให้เลย
- กด "ออกจากระบบ" แล้วล็อกอินเป็นหน่วยงานได้ด้วยชื่อผู้ใช้ `opd01`, `er01` หรือ `ipd01` (รหัสผ่านอะไรก็ได้)
- ทุกปุ่มกดได้จริง แต่ข้อมูลหายเมื่อรีเฟรชหน้า

## อัปเดตเมื่อแก้หน้าเว็บจริง

`app/index.html`, `app/app.js`, `app/style.css` สร้างจาก `static/` ถ้าแก้ไฟล์ใน `static/` ให้รันคำสั่งนี้ที่รากโปรเจกต์เพื่ออัปเดตโฟลเดอร์นี้:

```bash
python tools/build_codebase.py
```

ส่วน `app/mock-api.js` เขียนแยกไว้ ถ้าเพิ่ม API ใหม่ใน `server.py` ต้องเพิ่มใน mock ด้วย
