# งานบริหารเวชภัณฑ์ (คลังกลาง) รพ.ตาพระยา

ระบบเบิกยา เวชภัณฑ์ และพัสดุจากคลังกลางบนเว็บ หน่วยงานเลือกสินค้าจาก 7 คลังรวมเป็นใบเบิกเดียว คลังกลางอนุมัติ จ่ายของ และตัดสต็อก

- ต้องมี **Python 3.10 ขึ้นไป** เท่านั้น ไม่ต้องติดตั้งไลบรารีเพิ่ม ไม่ต้องต่ออินเทอร์เน็ต
- ข้อมูลเก็บในไฟล์เดียว `data/central-store.db` (SQLite) — **ไฟล์นี้มีเลขบัตรประชาชน ห้ามส่งขึ้น GitHub** (ตั้ง `.gitignore` ไว้แล้ว)

## เริ่มใช้ครั้งแรก

1. ติดตั้ง Python จาก https://www.python.org/downloads/ (ติ๊ก "Add python.exe to PATH")
2. ดับเบิลคลิก `run.bat` เบราว์เซอร์จะเปิด http://127.0.0.1:8000
3. หน้าแรกคือ **ตั้งค่าระบบครั้งแรก** กรอกชื่อและเลขบัตรประชาชนของผู้ดูแลคลังกลางคนแรก แล้วระบบจะให้ตั้งรหัสผ่านใหม่ทันที
4. เข้าเมนูตามลำดับนี้แล้วใส่ข้อมูลจริง
   1. **ทะเบียนหน่วยเบิกในรพ.** — หน่วยงานที่เบิกได้
   2. **สินค้า/สต็อก** — สินค้าของแต่ละคลังพร้อมยอดยกมา
   3. **ทะเบียนเจ้าหน้าที่คลังกลาง / ผู้เบิกสินค้า / ผู้รับสินค้า** — รายชื่อที่ใช้เลือกในใบเบิก
   4. **บัญชีผู้ใช้** — บัญชีของเจ้าหน้าที่แต่ละหน่วยงาน (เลขบัตรประชาชน ระบบตรวจหลักสุดท้ายให้)

### ระบบ รพ. และ รพ.สต.

หน้าแรกให้เลือกช่องทาง **ใช้งานโดย รพ.** หรือ **ใช้งานโดย รพ.สต.** ก่อนเข้าสู่ระบบ

- บัญชีหน่วยงานเข้าได้เฉพาะระบบของตัวเอง บัญชีเดิมทั้งหมดเป็นของ รพ.
- ผู้ดูแลคลังกลางเข้าได้ทั้ง 2 ระบบ มีได้ไม่เกิน 5 คน
- เพิ่มบัญชีของ รพ.สต.: ผู้ดูแลเข้าทาง "ใช้งานโดย รพ.สต." → เมนูบัญชีผู้ใช้ (แต่ละระบบเห็นเฉพาะบัญชีของตัวเองและผู้ดูแลคลังกลาง)
- ระบบ รพ.สต. ยังไม่มีฐานข้อมูลอื่นนอกจากบัญชีผู้ใช้ ทุกหน้าว่าง และเข้าถึงข้อมูลของ รพ. ไม่ได้

## นำเข้าสินค้าจาก Excel

เมนู **สินค้า/สต็อก** → ปุ่ม **นำเข้าจาก Excel** → ลากไฟล์มาวาง (หรือกดเลือกไฟล์) → ตรวจผล → กด **นำเข้า**

- รองรับ `.xlsx` และ `.csv` ใช้แผ่นงานแรกของไฟล์ ไม่เกิน 5,000 รายการ (ไฟล์ `.xls` แบบเก่า ให้เปิดใน Excel แล้วบันทึกเป็น `.xlsx`)
- หัวตาราง: **รหัสสินค้า, ชื่อสินค้า, คลัง, หน่วยนับ** (บังคับ) และ **คงเหลือ, จุดสั่งซื้อ** (ไม่บังคับ) ดาวน์โหลดไฟล์ต้นแบบได้ในหน้าต่างนำเข้า
- คอลัมน์คลัง ใส่ชื่อหรือรหัสคลังก็ได้ เช่น `คลังยา` `ยา` หรือ `DRG`
- รหัสใหม่ → เพิ่มสินค้า ใช้ "คงเหลือ" เป็นยอดยกมา · รหัสที่มีอยู่แล้ว → อัปเดตชื่อ คลัง หน่วยนับ จุดสั่งซื้อ (ไม่เพิ่มซ้ำ)
- ยอดคงเหลือของสินค้าที่มีอยู่แล้วจะไม่เปลี่ยน เว้นแต่ติ๊ก "ปรับยอดคงเหลือให้ตรงกับไฟล์" (ใช้ตอนตรวจนับสต็อก ทุกการปรับบันทึกในประวัติสต็อก)
- ระบบแสดงผลตรวจทุกแถวก่อนบันทึก แถวที่ผิด (เช่น ไม่รู้จักคลัง ไม่มีหน่วยนับ รหัสซ้ำในไฟล์) จะถูกข้าม

## ล้างใบเบิกทั้งหมดก่อนเริ่มใช้จริง

ใช้ครั้งเดียวหลังทดลองระบบ เพื่อลบใบเบิกทดสอบทั้งหมด

1. ดับเบิลคลิก `reset-requisitions.bat` (ระบบเปิดอยู่ก็ได้)
2. อ่านจำนวนที่จะถูกลบ แล้วพิมพ์ `YES` (ตัวพิมพ์ใหญ่) กด Enter — พิมพ์อย่างอื่นจะยกเลิก

สิ่งที่เกิดขึ้น: สำรองฐานข้อมูลอัตโนมัติก่อน (`data/backups/`) → คืนสต็อกของใบที่จ่ายไปแล้วกลับเข้าคลัง (บันทึกในประวัติสต็อก) → ลบใบเบิกทุกใบ ทุกสถานะ → เลขที่ใบเบิกเริ่มนับ 0001 ใหม่
สินค้า หน่วยเบิก ทะเบียนรายชื่อ และบัญชีผู้ใช้ **ยังอยู่ครบ** · ถ้าล้างผิด กู้คืนจากไฟล์สำรองได้ (ดูหัวข้อสำรองข้อมูล)

## ติดตั้งให้เครื่องอื่นในโรงพยาบาลใช้ (วงแลน)

1. เลือกเครื่องที่เปิดตลอดเวลา ขอให้ IT ตั้ง IP คงที่ เช่น `192.168.1.50`
2. `run.bat` ตั้ง `HOST=0.0.0.0` ไว้แล้ว เครื่องอื่นเปิดได้ที่ `http://192.168.1.50:8000`
3. ครั้งแรกที่รัน Windows จะถามเรื่อง Firewall ให้กด **Allow** เฉพาะ Private network
4. ขอ IT ตั้งชื่อเว็บภายใน เช่น `http://store.tpy.local` ให้จำง่าย

### ให้ระบบเปิดเองเมื่อเปิดเครื่อง (Windows) — ไม่ต้องเปิด run.bat อีก

1. ปิดหน้าต่าง `run.bat` ถ้าเปิดอยู่
2. **คลิกขวา** `install-autostart.bat` → **Run as administrator** → กด Yes
3. ต้องขึ้นข้อความสีเขียว `OK: the server is running in the background...`

ระบบจะทำงานเบื้องหลัง (ไม่มีหน้าต่างสีดำ) เปิดเองทุกครั้งที่เปิดเครื่อง แม้ยังไม่มีใครล็อกอิน และถ้าหยุดเองจะเปิดใหม่ภายใน 1 นาที
บันทึกการทำงานอยู่ที่ `data/server.log` · ติดตั้งแล้ว**ไม่ต้องใช้ run.bat อีก**

| ไฟล์ (คลิกขวา → Run as administrator) | ใช้เมื่อ |
|---|---|
| `restart-server.bat` | หลังดาวน์โหลดระบบรุ่นใหม่ ให้ระบบใช้โค้ดใหม่ |
| `uninstall-autostart.bat` | เลิกเปิดอัตโนมัติ กลับไปใช้ run.bat |

ดูสถานะได้ที่ Task Scheduler → Task Scheduler Library → `CentralStore`

### เครื่องต้องไม่หลับ

ถ้าใช้โน้ตบุ๊กเป็นเซิร์ฟเวอร์: Settings → System → Power → Screen and sleep → ตั้ง **Sleep = Never** ทั้งตอนเสียบปลั๊กและใช้แบตเตอรี่
และ Control Panel → Power Options → Choose what closing the lid does → **Do nothing** (เครื่องหลับเมื่อไร เว็บใช้ไม่ได้ทันที)

## เปิดใช้ผ่านอินเทอร์เน็ตด้วย Cloudflare Tunnel

Cloudflare Tunnel ทำให้ได้ลิงก์ `https://` ที่เปิดได้จากทุกที่ **โดยระบบและข้อมูลยังอยู่ที่เครื่องนี้** ไม่ต้องเปิดพอร์ตที่เราเตอร์ ไม่ต้องมี IP จริง
เครื่องนี้ยังต้องเปิดทิ้งไว้และรัน `run.bat` ตลอดเหมือนเดิม

> ก่อนเปิดสู่อินเทอร์เน็ต ควรแจ้งผู้รับผิดชอบด้านข้อมูล/IT ของโรงพยาบาล เพราะระบบมีเลขบัตรประชาชน (PDPA)

### ขั้นที่ 1: ติดตั้ง cloudflared

เปิด cmd แบบ **Run as administrator** แล้วพิมพ์

```bat
winget install --id Cloudflare.cloudflared
```

ปิด cmd แล้วเปิดใหม่ พิมพ์ `cloudflared --version` ต้องขึ้นเลขเวอร์ชัน

### ขั้นที่ 2: ทดลองด้วยลิงก์ชั่วคราว (ไม่ต้องสมัครอะไร)

1. เปิด `run.bat` ทิ้งไว้
2. ดับเบิลคลิก `tunnel-test.bat` รอสักครู่จะมีบรรทัด `https://xxxx-xxxx.trycloudflare.com`
3. ส่งลิงก์นั้นให้คนอื่นเปิดได้จากทุกที่ (มือถือ 4G ก็ได้)

ลิงก์นี้เปลี่ยนทุกครั้งที่เปิด `tunnel-test.bat` ใหม่ และปิดหน้าต่างเมื่อไรลิงก์ใช้ไม่ได้ **ใช้ทดลองเท่านั้น**

### ขั้นที่ 3: ลิงก์ถาวรด้วยชื่อโดเมนของตัวเอง

ต้องมี: บัญชี Cloudflare (ฟรี) และชื่อโดเมน (ประมาณ 300–500 บาท/ปี ซื้อผ่าน Cloudflare ได้เลยที่ Domain Registration)

1. เข้า https://dash.cloudflare.com → เพิ่มโดเมนเข้า Cloudflare (ถ้าซื้อจากที่อื่น ให้เปลี่ยน nameserver ตามที่ Cloudflare บอก)
2. เข้า **Zero Trust** (เมนูซ้าย) → **Networks → Tunnels** → **Create a tunnel** → เลือก **Cloudflared** → ตั้งชื่อ เช่น `central-store`
3. เลือก **Windows** ระบบจะแสดงคำสั่ง `cloudflared.exe service install eyJ...` ให้คัดลอกไปรันใน cmd แบบ **Run as administrator**
   (ติดตั้งเป็น Windows Service เปิดเองทุกครั้งที่เปิดเครื่อง ไม่ต้องใช้ `tunnel-test.bat` อีก)
4. หน้า **Public Hostname** กรอก
   - Subdomain: `store` · Domain: โดเมนของคุณ
   - Service Type: `HTTP` · URL: `localhost:8000`
5. กด Save แล้วเปิด `https://store.<โดเมนของคุณ>` ได้เลย

(ชื่อเมนูใน Cloudflare อาจเปลี่ยนเล็กน้อยตามเวอร์ชันของหน้าเว็บ)

### ขั้นที่ 4: เพิ่มด่านยืนยันตัวตนด้วย Cloudflare Access (แนะนำมาก)

ให้คนที่จะเข้าเว็บต้องยืนยันอีเมลก่อน ถึงจะเห็นหน้าเข้าสู่ระบบ (ฟรีไม่เกิน 50 คน)

1. Zero Trust → **Access → Applications** → **Add an application** → **Self-hosted**
2. Application domain: `store.<โดเมนของคุณ>`
3. เพิ่ม Policy: Action = **Allow**, Include = **Emails** แล้วใส่อีเมลของเจ้าหน้าที่ที่ใช้ระบบ
   (หรือ **Emails ending in** ถ้าโรงพยาบาลมีอีเมลโดเมนของตัวเอง)
4. Login method: **One-time PIN** — ระบบส่งรหัส 6 หลักไปที่อีเมลทุกครั้งที่เข้าจากเครื่องใหม่

ระบบรู้เองว่าเปิดผ่าน HTTPS ของ Cloudflare (ดูจาก header ที่ cloudflared ส่งมาจากเครื่องเดียวกัน) คุกกี้จะถูกตั้งเป็น Secure ให้อัตโนมัติ ส่วนเครื่องในวงแลนที่เปิดผ่าน `http://IP:8000` ยังใช้ได้ตามปกติ

## สำรองข้อมูล

ดับเบิลคลิก `backup.bat` หรือรัน `python server.py --backup` ได้แม้ระบบกำลังทำงาน ไฟล์อยู่ที่ `data/backups/` เก็บ 30 ไฟล์ล่าสุด

ตั้งให้สำรองทุกวันด้วย **Task Scheduler** → Create Basic Task → Daily 18:00 → Start a program → เลือก `backup.bat`
แล้วคัดลอกโฟลเดอร์ `data/backups/` ไปเก็บอีกเครื่องหรือไดรฟ์ภายนอกเป็นประจำ (ถ้าเครื่องเสีย ข้อมูลในเครื่องหายด้วย)

กู้คืน: หยุดระบบ → คัดลอกไฟล์สำรองมาทับ `data/central-store.db` → เปิดระบบ

## ตั้งค่า (environment variable)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `HOST` | `127.0.0.1` | `0.0.0.0` = ให้เครื่องอื่นในเครือข่ายเข้าได้ |
| `PORT` | `8000` | พอร์ตของเว็บ |
| `CENTRAL_STORE_DB` | `data/central-store.db` | ตำแหน่งฐานข้อมูล |
| `BACKUP_DIR` | `data/backups` | ที่เก็บไฟล์สำรอง |
| `HTTPS` | `0` | ตั้ง `1` ให้คุกกี้เป็นแบบ HTTPS เสมอ (ไม่ต้องตั้งถ้าใช้ Cloudflare Tunnel) |
| `SESSION_HOURS` | `12` | ล็อกอินค้างไว้ได้นานเท่าไร |

## ความปลอดภัย

- รหัสผ่านเริ่มต้นคือเลข 5 ตัวท้ายของบัตร **ใช้ได้ครั้งเดียว** เข้าระบบแล้วต้องตั้งรหัสใหม่ (อย่างน้อย 8 ตัว มีตัวอักษรปน ห้ามมีเลขบัตร) ก่อนจะใช้เมนูใดได้
- ผู้ใช้เปลี่ยนรหัสผ่านเองได้ที่ปุ่ม "เปลี่ยนรหัสผ่าน" ด้านล่างแถบซ้าย (เครื่องอื่นที่ล็อกอินค้างไว้จะถูกออกจากระบบ)
- ลืมรหัสผ่าน: ผู้ดูแลเข้าเมนูบัญชีผู้ใช้ → แก้ไข → รหัสผ่าน = รีเซ็ต แล้วผู้ใช้เข้าด้วยเลข 5 ตัวท้ายและตั้งรหัสใหม่
- รหัสผ่านเก็บแบบเข้ารหัส (PBKDF2) ไม่มีใครเห็นรหัสจริง
- ใส่รหัสผิด 5 ครั้ง บัญชีถูกล็อก 15 นาที ผู้ดูแลปลดล็อกได้ทันทีโดยกด "แก้ไข" แล้ว "บันทึก" ที่บัญชีนั้น
- เซิร์ฟเวอร์ตรวจสิทธิ์ทุกคำขอ: หน่วยงานเห็นเฉพาะใบเบิกและทะเบียนของตัวเอง อนุมัติ จ่ายของ และแก้สต็อกได้เฉพาะผู้ดูแลคลังกลาง
- การตัดสต็อกล็อกฐานข้อมูลระหว่างทำ ไม่ติดลบแม้จ่ายของพร้อมกันหลายคน
- **ข้อควรระวัง:** บัญชีที่สร้างแล้วแต่เจ้าของยังไม่เคยเข้าระบบ ยังใช้รหัสเริ่มต้น (5 ตัวท้ายของบัตร) อยู่ ใครรู้เลขบัตรก็ตั้งรหัสแทนได้ ควรให้ทุกคนเข้าระบบครั้งแรกโดยเร็ว หรือสร้างบัญชีเมื่อจะใช้จริง เลขบัตรเป็นข้อมูลส่วนบุคคลตาม PDPA

| `restart-server.bat`, `uninstall-autostart.bat` | เริ่มระบบเบื้องหลังใหม่ / เลิกเปิดอัตโนมัติ |

`static/app.js` และ `static/style.css` เป็นไฟล์เดียวกับตัวอย่างใน `project/uploads/codebase/app/` (ตัวอย่างนั้นใช้ข้อมูลจำลอง `mock-api.js` ไม่ต้องรันเซิร์ฟเวอร์) ถ้าแก้หน้าเว็บ ให้แก้ที่ `static/` แล้วคัดลอกไปที่ตัวอย่างด้วย
