# Inventory
TPY Inventory Management

ระบบเบิกพัสดุจากคลังของโรงพยาบาลตาพระยา หน่วยงานต่าง ๆ ล็อกอินเข้ามาเลือกสินค้าและจำนวนที่จะเบิก (ระบบแสดงหน่วยนับของสินค้าให้) เจ้าหน้าที่คลังอนุมัติและจ่ายของ แล้วสต็อกจะถูกตัดอัตโนมัติ

## ขั้นตอนการเบิก

| ขั้น | ใครทำ | บันทึกชื่อ | สต็อก |
|---|---|---|---|
| 1. ขอเบิก | หน่วยงาน | ผู้เบิก | ยังไม่ตัด |
| 2. อนุมัติ (แก้จำนวนที่อนุมัติได้) หรือไม่อนุมัติ พร้อมเหตุผล | ผู้ดูแลคลัง | ผู้อนุมัติ | ยังไม่ตัด |
| 3. จ่ายของ (แก้จำนวนที่จ่ายจริงได้) | ผู้ดูแลคลัง | ผู้จ่าย, ผู้รับ | **ตัดสต็อก** |

- หน่วยงานยกเลิกใบเบิกเองได้ ตราบใดที่ยังไม่ได้อนุมัติ
- ถ้าของในคลังไม่พอ ระบบจะไม่ยอมให้จ่าย และแจ้งว่ารายการไหนขาดเท่าไร
- พิมพ์ใบเบิกได้ (ขนาด A4) มีช่องเซ็นชื่อ ผู้เบิก ผู้อนุมัติ ผู้จ่าย ผู้รับ
- เลขที่ใบเบิกรันตามปี พ.ศ. เช่น `REQ2569-0001`

## สิทธิ์ผู้ใช้

| สิทธิ์ | ทำอะไรได้ |
|---|---|
| **หน่วยงาน** | เบิกสินค้า ดูใบเบิกของหน่วยงานตัวเองเท่านั้น |
| **ผู้ดูแลคลัง** | ทุกอย่าง: อนุมัติ จ่ายของ เพิ่มสินค้า รับของเข้า ปรับสต็อก จัดการหน่วยงานและบัญชีผู้ใช้ ดูประวัติสต็อก |

## วิธีรัน (Windows)

ดับเบิลคลิก `run.bat` ระบบจะเปิดเบราว์เซอร์ไปที่ http://127.0.0.1:8000 ให้เอง หรือรันจาก PowerShell:

```bash
python server.py --open
```

ต้องมี Python 3.10 ขึ้นไปเท่านั้น ไม่ต้องติดตั้งไลบรารีเพิ่ม

**เปิดครั้งแรก** ระบบจะให้สร้างบัญชีผู้ดูแลคลัง จากนั้นเพิ่มตามลำดับ:
1. เมนู **หน่วยงาน** เช่น งานผู้ป่วยนอก (OPD), ห้องฉุกเฉิน (ER)
2. เมนู **ผู้ใช้** สร้างบัญชีให้แต่ละหน่วยงาน
3. เมนู **สินค้า/สต็อก** เพิ่มสินค้า หน่วยนับ และยอดคงเหลือตอนนี้

## ให้หน่วยงานอื่นในโรงพยาบาลเข้าใช้

ค่าเริ่มต้นเปิดได้เฉพาะเครื่องที่รันระบบ ถ้าจะให้เครื่องอื่นในวงแลนของโรงพยาบาลเข้าได้ ให้ตั้ง `HOST` ก่อนรัน:

```bash
$env:HOST="0.0.0.0"; python server.py
```

แล้วให้หน่วยงานเปิด `http://<IP ของเครื่องนี้>:8000` (อาจต้องอนุญาตพอร์ต 8000 ใน Windows Firewall) ระบบใช้ HTTP ธรรมดา จึงควรใช้ภายในวงแลนของโรงพยาบาลเท่านั้น ไม่ควรเปิดออกอินเทอร์เน็ต

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `HOST` | `127.0.0.1` | `0.0.0.0` = ให้เครื่องอื่นในวงแลนเข้าได้ |
| `PORT` | `8000` | พอร์ตของเว็บ |
| `INVENTORY_DB` | `data/inventory.db` | ตำแหน่งไฟล์ฐานข้อมูล |

## ข้อมูลและการสำรอง

ข้อมูลทั้งหมดอยู่ในไฟล์ `data/inventory.db` (SQLite) ไฟล์นี้ **ไม่ถูกส่งขึ้น GitHub** ควรสำรองไฟล์นี้เป็นประจำ (ปิดระบบก่อนคัดลอก หรือคัดลอกไฟล์ `inventory.db-wal` ไปด้วย)

รหัสผ่านเก็บแบบเข้ารหัสทางเดียว (PBKDF2) ผู้ดูแลคลังตั้งรหัสผ่านใหม่ให้ผู้ใช้ที่ลืมรหัสได้ในเมนู **ผู้ใช้**
