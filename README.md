# Inventory
TPY Inventory Management

ระบบคลังสินค้าบนเว็บที่เชื่อมกับงาน CNC ใช้ติดตามวัตถุดิบ ดอกกัด/ทูล สินค้าสำเร็จรูป และไฟล์ G-code ในที่เดียว

## ความสามารถ

| เรื่อง | ระบบทำอะไรให้ |
|---|---|
| ตัดสต็อกวัตถุดิบ | กด **เริ่มผลิต** แล้วระบบเบิกวัตถุดิบตามสูตรต่อชิ้น × จำนวน ถ้าของไม่พอจะแจ้งว่าขาดอะไรเท่าไร |
| ดอกกัด/ทูล | สะสมเวลาใช้งานของแต่ละดอกหลังจบงาน เตือนเมื่อใช้ถึง 80% ของอายุ ปุ่ม **เปลี่ยนดอก** ตัดดอกสำรองและรีเซ็ตเวลา |
| รับชิ้นงานเข้าคลัง | กด **ผลิตเสร็จ** แล้วกรอกจำนวนชิ้นงานดี ระบบรับเข้าคลังสินค้าสำเร็จรูปให้ |
| ไฟล์ G-code | อัปโหลดไฟล์ ระบบประมาณเวลาเครื่องต่อชิ้น แยกเวลาตามเบอร์ทูล (T) จับคู่กับดอกในระบบให้ และดาวน์โหลดไฟล์กลับได้ |
| ประวัติสต็อก | ทุกการรับ/เบิก/ปรับ ถูกบันทึกพร้อมยอดคงเหลือและเลขงาน |

## วิธีรัน (Windows)

ดับเบิลคลิก `run.bat` ระบบจะเปิดเบราว์เซอร์ไปที่ http://127.0.0.1:8000 ให้เอง

หรือรันจาก PowerShell:

```bash
python server.py --open
```

ต้องมี Python 3.10 ขึ้นไปเท่านั้น ไม่ต้องติดตั้งไลบรารีเพิ่ม ข้อมูลเก็บที่ `data/inventory.db` (SQLite) ไฟล์นี้ไม่ถูกส่งขึ้น GitHub ควรสำรองไว้เอง

ตั้งค่าได้ผ่าน environment variable:

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `8000` | พอร์ตของเว็บ |
| `HOST` | `127.0.0.1` | ตั้งเป็น `0.0.0.0` ถ้าต้องการให้เครื่องอื่นในวงแลนเปิดได้ (ระบบยังไม่มีล็อกอิน) |
| `INVENTORY_DB` | `data/inventory.db` | ตำแหน่งไฟล์ฐานข้อมูล |
| `RAPID_MM_PER_MIN` | `5000` | ความเร็วเดินเปล่า G0 ของเครื่อง ใช้ประมาณเวลา |

## ขั้นตอนใช้งาน

1. **วัตถุดิบ / ดอกกัด / สินค้าสำเร็จรูป** — เพิ่มรายการและยอดยกมา ใส่เบอร์ทูล (T) ให้ดอกกัดตรงกับที่ตั้งในเครื่อง
2. **โปรแกรม G-code** — อัปโหลดไฟล์ เลือกชิ้นงานที่ได้ ใส่วัตถุดิบที่ใช้ต่อชิ้น ดอกกัดจะถูกจับคู่จากคำสั่ง T ให้อัตโนมัติ
3. **งาน CNC** — สั่งผลิต → เริ่มผลิต (เบิกวัตถุดิบ) → ผลิตเสร็จ (รับชิ้นงาน + บันทึกเวลาดอกกัด) หรือยกเลิก (คืนวัตถุดิบ)

## เชื่อมกับเครื่อง CNC

ตอนนี้กดเริ่ม/จบงานจากหน้าเว็บ ภายหลังถ้าใช้ [CNCjs](https://github.com/cncjs/cncjs) หรือโปรแกรมคุมเครื่องอื่น สามารถให้เรียก API นี้ตอนงานจบได้เลย:

```bash
curl -X POST http://127.0.0.1:8000/api/jobs/1/complete -H "Content-Type: application/json" -d "{\"good_qty\": 10, \"machine_minutes\": 42}"
```

API หลัก:

| Method | Path | ใช้ทำ |
|---|---|---|
| GET/POST | `/api/materials`, `/api/tools`, `/api/products` | ดู/เพิ่มรายการ |
| PUT/DELETE | `/api/{ประเภท}/{id}` | แก้ไข/ลบ |
| POST | `/api/{ประเภท}/{id}/adjust` | รับเข้า/เบิกออก `{"delta": 5, "reason": "..."}` |
| POST | `/api/tools/{id}/replace` | เปลี่ยนดอกใหม่ |
| GET/POST | `/api/programs` | ดู/เพิ่มโปรแกรม G-code |
| GET | `/api/programs/{id}/gcode` | ดาวน์โหลดไฟล์ G-code |
| POST | `/api/gcode/analyze` | ประมาณเวลาจาก G-code `{"gcode": "..."}` |
| GET/POST | `/api/jobs` | ดู/สร้างงาน |
| POST | `/api/jobs/{id}/start` · `complete` · `cancel` | เปลี่ยนสถานะงาน |
| GET | `/api/movements?type=materials` | ประวัติสต็อก |
| GET | `/api/summary` | ข้อมูลหน้าภาพรวม |

> เวลาที่คำนวณจาก G-code เป็นค่าประมาณ (ไม่รวมการเร่ง/หน่วงความเร็วของเครื่อง) ถ้ากรอกเวลาจริงตอนจบงาน ระบบจะใช้เวลาจริงกระจายให้ดอกกัดแต่ละดอกตามสัดส่วนแทน
